The JS port is checked against real Scilab (web/test/compare.mjs): for every lab and several variants it prints the same lines as the original .sce script. The console output here is translated from the scripts’ Ukrainian into English. Scilab’s rand() generator is reproduced exactly, so the graphs match the ones Scilab draws.
